# Ralph Progress Log
Started: Thu Mar 12 02:32:13 CDT 2026

## Codebase Patterns
- TSV files live in `lexicons/` directory with tab-separated columns
- Language IDs in `languages.tsv` use ISO 639-3 codes (e.g., `eng`, `cmn`, `arb`)
- JSON arrays/objects are embedded directly in TSV fields (properly escaped with double quotes)
- Typecheck command: `npm run check` (runs `tsc`)
- Pre-existing type errors exist in the codebase; data-only TSV changes don't affect typecheck
- Always validate language_id values against languages.tsv before committing
- TSV loader pattern: private cached field → private load method (with parseTsv/getIdx) → async get methods with optional filters
- API route pattern: GET /api/{resource} (list with filters), GET /api/{resource}/:id (single), GET /api/languages/:id/{resource} (by language)
- Routes are registered in server/routes.ts, storage methods in server/tsv-storage.ts
- Interface types for TSV data are exported from tsv-storage.ts
- Client code cannot import from server — duplicate interfaces locally for API response types
- TypeScript target doesn't support Set spreading; use `Array.from(set)` instead
- UI panel pattern: sliding right panel with `isOpen`/`onClose` props, overlay backdrop, triggered from header buttons

# ML link-prediction baselines (Phase 2, US-003)

TransE / ComplEx / RotatE knowledge-graph embedding baselines trained on the
committed triples splits (US-002). These establish the **metric floor** all
future corpus growth and neurosymbolic work is judged against — so every
number below is pinned to an exact corpus version, split manifest, and seed.

> Regenerated by `uv run linguascrape-train-baselines` (see *Reproduce*).
> This file is committed; the trained embeddings and MLflow runs are not (DVC-tracked / git-ignored respectively).

## Trained embeddings

Each model's entity-embedding matrix is exported to
`ml/data/embeddings/<model>/entity_embeddings.npy` (row-aligned to
`ml/data/triples/entities.tsv` index order) with a `metadata.json` sidecar,
and DVC-tracked under `ml/data` for reuse (GraphRAG, the Scallop pilot).

## Reproduce

```bash
cd ml
uv run --project . dvc pull   # fetch DVC-tracked splits (from repo root)
uv run linguascrape-train-baselines   # train all 3, log MLflow, rewrite doc
# re-pin embeddings: cd .. && uv run --project ml dvc add ml/data && dvc push
```

Metrics are logged to the `linguascrape-baselines` MLflow experiment (local file backend; `uv run mlflow ui`).

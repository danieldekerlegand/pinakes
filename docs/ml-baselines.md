committed triples splits (US-002). These establish the **metric floor** all

## Logical consistency (US-005)

Each baseline's top-1 link predictions (both directions, per test
triple) are checked against the symbolic rules — **descent acyclicity**,
canonical-schema **from/to type** constraints (`shared/canonical-schema.json`),
and relation **antisymmetry** — by `linguascrape_ml.consistency`. The violation
counts are ratcheted in CI against `ml/manifests/consistency-baseline.json`
(a monotone gate, mirroring `docs/convergence-qa-baseline.json`); a deliberate
rise is re-baselined with `uv run linguascrape-check-consistency --write-baseline`.

| Model | Predictions | Descent cycles | Schema type breaches | Asymmetry violations |
| --- | --- | --- | --- | --- |
| TransE | 379 | 295 | 4 | 332 |
| ComplEx | 401 | 2 | 76 | 2 |
| RotatE | 403 | 0 | 43 | 0 |

> Predictions are the model's single best (top-1) head- and tail-completions of
> each test query (`ml/predictions/<model>.tsv`, committed). A deliberately
> conservative floor: with a near-random baseline most predictions are schema-
> plausible high-degree nodes, so violations start low — the ratchet guarantees
> future models (and corpus growth) never make the predictions *less* logically
> consistent without review.

## KGQA accuracy (tier 3, US-004)

The third eval tier scores whether a system **answers the held-out multi-hop
reasoning questions correctly** (`ml/data/kgqa/eval.jsonl`, the registered
held-out split from US-003) and whether its answer is **grounded in the
evidence it retrieved**. Deterministic + offline (network-free), so the numbers
below are a byte-reproducible floor committed to `ml/manifests/kgqa-eval-baseline.json`.

- Held-out records: **394** (path 225 / derivation 169); retrieval depth **2**.

| System | Exact | Normalized | Grounding | Answered |
| --- | --- | --- | --- | --- |
| graph-retrieval | 98.5% | 98.5% | 100.0% | 98.5% |
| no-retrieval | 1.5% | 1.5% | 0.0% | 0.0% |

> `graph-retrieval` is the GraphRAG floor — it expands a depth-bounded
> neighbourhood around the subject and answers by walking the reasoning chain
> over the retrieved edges, so a chain deeper than the retrieval depth is
> answered wrong (an honest depth-limited floor, not an oracle). `no-retrieval`
> is the control: with no retrieved subgraph it can only restate the subject,
> so the gap between the two rows is the value the retrieved evidence adds.
> The *live* variant answers the same retrieved subgraphs through the existing
> Gemini proxy (`/api/graph/retrieve` + the LLM) and is measured locally — see
> `docs/kgqa-dataset.md`; it is never required for CI.

### Logical consistency over KGQA evidence (tier 2)

The structured evidence each system grounds its answers in is itself a set of
predicted edges, so the tier-2 checks (`linguascrape_ml.consistency`) run over
it — descent acyclicity, canonical-schema `from`/`to` type constraints, and
relation antisymmetry. The retrieved evidence is drawn from real corpus edges,
so any breach here is a genuine corpus/schema observation (e.g. `DESCENDS_FROM`
edges among node types the schema's `from`/`to` sets do not yet declare), not a
model error — descent cycles and antisymmetry violations should stay at zero.

| System | Evidence edges | Descent cycles | Schema type breaches | Asymmetry violations |
| --- | --- | --- | --- | --- |
| graph-retrieval | 370 | 0 | 20 | 0 |
| no-retrieval | 0 | 0 | 0 | 0 |

## Evaluation tiers

The eval harness judges the corpus from three angles — cross-linked here so
a reader sees the whole picture:

1. **Statistical (tier 1)** — link-prediction MRR / Hits@k (*Results* above).
2. **Symbolic (tier 2)** — logical-consistency violation counts (*Logical
   consistency* above, and over KGQA evidence in this section).
3. **Question answering (tier 3)** — held-out KGQA accuracy + evidence
   grounding (this section).

Reproduce tier 3: `cd ml && uv run linguascrape-eval-kgqa` (needs the
DVC-tracked export + eval split; `uv run --project ml dvc pull` first).

## Rule-guided link prediction (Phase 5, US-003)

The neurosymbolic pilot: a neural edge predicate over the **transe** embeddings, with the corpus's *ancestor* transitive-closure rule propagating its soft edge probabilities under Scallop's `minmaxprob` provenance (`Pr[ancestor] = max-path of min-edge-prob`), trained on the US-002 queries and evaluated on the same held-out `test` split as the baselines. The headline verdict is the **ablation** (rule on vs the identical predicate with the rule off, one harness); the PyKEEN row is the committed floor, measured by its own evaluator.

> **Verdict:** rule guidance **neutral** — no material MRR change vs the direct-only ablation.

| System | MRR | Hits@1 | Hits@3 | Hits@10 |
| --- | --- | --- | --- | --- |
| PyKEEN transe (baseline floor) | 0.0071 | 0.0000 | 0.0067 | 0.0111 |
| Neural predicate, rule OFF (ablation) | 0.0062 | 0.0000 | 0.0029 | 0.0087 |
| Rule-guided (neural + ancestor rule) | 0.0060 | 0.0000 | 0.0000 | 0.0087 |

Filtered ranks over 344 head/tail queries (seed 20260713, 40 epochs, 3-hop min-max propagation, CPU). The neural-vs-PyKEEN gap reflects a different scorer *and* a different evaluator; the rule's own effect is the ablation rows.

### Logical consistency of the pilot's predictions (tier 2)

Each system's top-1 completions of the target-relation test queries run through the same `linguascrape_ml.consistency` checks as the baselines — rule-off vs rule-on over the identical prediction set, so the rule's effect on logical consistency is isolated too.
